# Animals Asset Pack

Downloaded from [Animals Asset Pack by styloo](https://styloo.itch.io/animals). The original ZIP is preserved in `source/`.

## Included

- `glb/` — 7 binary glTF models: butterfly, cat, chicken, cow, dog, giraffe and ladybug
- `source/AnimalsAssetPack-original.zip` — original 8.6 MB download, including the FBX models and source notes
- `manifest.json` — asset list, source filenames and pack details
- `LICENSE.txt` — license information as stated on the itch.io asset page

The extracted GLBs are self-contained according to the creator's notes. The source archive names the chicken model `chichen.glb` and the giraffe `girafe.glb`; these two were normalized to `chicken.glb` and `giraffe.glb` here. Model contents were not modified.

The creator describes the pack as rigged, with animations for the dog, cow, giraffe and butterfly. The download page notes that animation, texture and normal data are embedded. The original archive contains FBX as well as GLB files; only GLBs are exposed in this library folder, consistent with the current GLB workspace.
