# KayKit Game Assets

Rebuilt from the categorized source archive at Documents/게임에셋/3D/KayKit/Assets.zip. Original package names and paths are preserved.

| Path | Contents |
|---|---|
| `Mdl/glTF` | `.gltf` files |
| `Mdl/GLB` | `.glb` files |
| `Mdl/glTF_Bin` | External `.bin` buffers |
| `Tex` | `.png` texture assets |

FBX, OBJ, and MTL files are not included, matching the selected format scope. External glTF buffer and image URIs have been rewritten to their corresponding `Mdl/glTF_Bin` and `Tex` paths. Character models, extra heads, props, and animations are present under their source package folders.

Available character-pack license files were carried over from the prior collection. See `README-Character-Library.md`.

Package paths under `Mdl` and `Tex` remain grouped by source pack.
