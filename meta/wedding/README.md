# meta/wedding — 몰루 웨딩홀 배포본

`/wedding` 장면(본식 홀)과 마을 서쪽 끝 웨딩홀 외관용 정적 GLB. 미터·Y-up, 앞 +z.

| 파일 | 용도 | 크기 |
|---|---|---:|

`chiffon` 재질(드레이프·베일)은 장면에서 반투명으로 바꿔 쓴다. `glow*` 재질(촛불·전구)은 발광으로 그린다.

## 원본·재현

meta 저장소 `node scripts/wedding.mjs <이름>` → 3d-maker `maker prop` (`npm run wedding`). 레시피는 meta `assets/wedding-*.prop.json`. 압축하지 않았다. 모두 `issues: []`. 경고는 `floating`(아치·현관에 매단 꽃송이, 샹들리에의 크리스털 방울)과 `not on the ground`(매달거나 손에 드는 것)뿐이고 의도된 것이다.
