# 실사 산호초 GLB v005

산호, 해양 생물, 해저 스캔 25종. GLB 합계 69.02 MB이며 내장 텍스처 73장은 모두 512×512 WebP다. Y-up 좌표계와 원본 장면의 배치·스케일을 사용한다.

로드에는 `EXT_meshopt_compression`, `KHR_mesh_quantization`, `EXT_texture_webp` 지원이 필요하다.

[credits.csv](credits.csv)에 파일별 저작자, 라이선스, 출처 URL과 원본 수치가 있다. 변경 사항은 메시 감면, 정점 양자화, Meshopt 압축, 512px 텍스처 리사이즈와 WebP 인코딩이다. CC BY 4.0 에셋을 재배포할 때는 해당 출처와 변경 사항을 함께 표시한다.
