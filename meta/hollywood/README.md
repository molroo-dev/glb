## 원본·재현

meta 저장소 `npm run hollywood`(= `node scripts/hollywood.mjs <이름>` → 3d-maker `maker prop`, 식물·바위는 `maker decimate`로 예산까지 줄임). 레시피는 meta `assets/hollywood-*.prop.json`. 모두 `issues: []`. 경고는 `sign`의 홈 커터 일부가 글자 밖·구멍 안에 떨어져 아무것도 깎지 않는 것과 작은 조각, 몇몇 소품의 부착 부품 `floating`(볼트·번호판·유리구, 본체 면에 붙어 있음)과 subdivide·묻힘으로 생긴 `min y` 정도다.

감축(`--error=0.02`): joshua 9,000, juniper 6,000, sage 1,500, chaparral 2,500, saguaro 4,000, boulder 1,200, overlook-rock 6,000 삼각형.
