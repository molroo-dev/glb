# meta/desert — 우유니 소금사막 배포본

`/desert` 장면(볼리비아 우유니 소금사막: 우기의 거울 지면, 투어 지프, 콜차니 소금 더미, 국기 광장)용 정적 GLB. 미터·Y-up, 앞 +z.

| 파일 | 용도 | 크기 |
|---|---|---:|
| `jeep.glb` | 투어 4x4 왜건. 길이 4.7 m·폭 1.86 m·지붕 1.92 m(바퀴 반지름 0.4 m, 바닥 y 0). 지붕 루프랙 슬랫 높이 2.06 m, 앞쪽에 방수포 덮인 짐, 뒤쪽 절반은 앉을 자리(장면의 좌석 4개). 스노클·불바·뒤 스페어타이어·사다리. 차체 재질 `paint`를 장면에서 지프마다 다시 칠한다. 전조등 `glow_head`·미등 `glow_tail`은 자체 발광 | 560 KB |
| `salt-mound.glb` | 소금 더미 하나, 약 1.5×1.3 m·높이 0.7 m, 각진 덩어리 면. 장면이 행렬로 늘어놓고 크기를 바꾼다 | 883 KB |
| `flags.glb` | 국기 광장: 지름 7 m 소금 단, 가운데 계단식 소금 블록 기둥, 뒤쪽 호를 따라 국기 게양대 9개(볼리비아 가운데 8.4 m, 한국·일본·페루·아르헨티나·이탈리아·독일·콜롬비아·네덜란드), 바람에 접힌 깃발 | 432 KB |

하늘·구름·별·은하수와 지면 반사, 지평선의 산줄기는 GLB가 아니라 장면 셰이더가 그린다.

## 원본·재현

meta 저장소 `npm run desert`(= `node scripts/desert.mjs <이름>` → 3d-maker `maker prop`). 레시피는 meta `assets/desert-*.prop.json`. 압축하지 않았다. 모두 `issues: []`; 경고는 지프의 작은 부품 몇 개 `floating`(문 손잡이·문틈 선, 차체 면에 붙어 있음)과 타이어 subdivide로 생긴 `min y = 0.003`뿐.
